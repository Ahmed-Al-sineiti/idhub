# Corvus — مواقع العملاء

كل مواقع العملاء في فولدر واحد، وصفحة رئيسية بتجمعهم.

## التشغيل
من الفولدر ده:
```
npm install
npm run dev
```
- الصفحة الرئيسية: http://localhost:3000
- كل موقع بياخد بورت لوحده (3001، 3002، ...)، واللينكات موجودة في الصفحة الرئيسية.

## الفولدرات
- `hub/`: الصفحة الرئيسية.
- `*-site/`: كل فولدر اسمه بيخلص بـ `-site` موقع عميل، وبيتضاف للصفحة الرئيسية لوحده.
- `wstudio-site/`: القالب الأصلي.

## إضافة عميل جديد
1. انسخ `wstudio-site` وسمّيه مثلاً `noura-site`.
2. غيّر `"name"` في `package.json` بتاعه لنفس اسم الفولدر.
3. عدّل `app/brand.css` و`data/site.ts`، وحط اللوجو في `public/brand`.
4. `npm install` وبعدها `npm run dev` من هنا.
